## Calmlings（Calm Studios）

可爱的 3D 小生物，治愈、平静，题材是成年人的日常自嘲。官网称累计 20 亿以上播放、每天一条百万播放；观众 78% 是女性、70% 在 25–54 岁。

读得出的规律：

- **播放最高的四条全是歌**：第一人称、押韵、唱的是身体和疲惫这类人人都有的小毛病。纯治愈的小贴士和「停一下」类只有十万到百万。
- **语气平静，内容自嘲**：唱的是累、疼、拖延，但角色可爱、画面干净、音乐轻，所以不丧。
- **靠转发传播**：分享率稳定在 0.3%–1.6%，文案常带「发给某某」。
- **和我们的差别**：他们的受众年龄偏大、女性为主；我们要的是 16–28 岁。结构可以学，题材要换。

### 他们的歌是怎么来的（2026-10-12 查到的）

- **「My lower back is killing me」是旧梗新唱**：套的是 Britney Spears《...Baby One More Time》的旋律，这句改词至少 2019 年就在推特上流传。旋律人人都会，观众第一秒就认出来，只需要处理改掉的词，所以信息量很低、笑点很快。
- **歌词是人写的**：视频文案里标了「Lyrics by @official_reuben_e」，话题标签有 #parodysong。
- **具体工具没有公开**：官网只说「人主导、AI 加速」，用 Google AI Studio 设计角色、写脚本；早期视频带 #midjourney 标签。音乐用什么做的、口型怎么对的，没查到。
- **行业里做唱歌角色的通行办法**：先把歌做出来（Suno 这类工具），再把音频喂给视频模型或对口型工具，让嘴跟着音频动；片段越短对得越准。我们用的 Seedance 支持上传音频作参考，这条路可行但还没试过。
- **版权**：套流行歌的旋律有被认领版权的风险（我们的 YouTube 旧视频已经被认领过一次）。公版旋律没有这个问题，而且更耳熟：摇篮曲、《小星星》、《生日快乐》、《划船歌》。

产品经理把 8 条参考视频连声音存进了 `projects/endscroll/references/`。下面是总监逐条看画面、量节奏、转写歌词之后的记录，取代上面只凭文字描述得出的印象。对比图在 `references/_analysis/first_frames.jpg` 和 `sheets_combined.jpg`。

### Calmlings（4 条，480 万到 2110 万播放）

| 项目 | 看到的 |
| --- | --- |
| 景别 | **脸的特写。** 角色的脸占画面宽度的一半以上，整条视频基本就是一张脸 |
| 第一帧 | **嘴已经张开在唱。** 四条的第一个词都在第 0 秒，没有前奏，没有铺垫 |
| 字 | **一次一小句，唱到哪显示到哪**，每句 2–5 个词，1.5–3 秒换一句。字就是唱的词，不是另一条信息。细的圆体或手写体，放在头顶上方 |
| 词量 | 9–15 秒唱 15–39 个词，每秒 1.4–2.9 个词 |
| 情绪 | 靠眼睛：耷拉的眼皮、无辜的大眼。内容是抱怨，表情是累和委屈，不是生气 |
| 镜头 | 1–4 个镜头，同一个角色、同一个场景，只换角度 |
| 声音 | 「lower back」用的是别的创作者的声音，有 1.98 万条视频在用；「I'm done scrolling」是他们自己的原声，已被 2242 条视频拿去用 |
| 互动 | 分享率 3.3%–3.7%，点赞率 5%–8% |

### 其他三家

- **Pudgy Penguins「How to turn in bed」**：2D 扁平卡通，两只企鹅，全程没有人声。标题从头挂到尾，结构是「错误做法配红叉 → 正确做法配绿勾」，不是「动作加反转」。分享率 3.9%。
- **Baboo & Biboo**：两只毛绒企鹅，没有人声，只有音乐。开头两行字交代情境，挂 5 秒；结尾 2 秒是带账号名的片尾卡。
- **MeetQuack**：没有字，没有人声，一个镜头的肢体喜剧。

### 之前判断错的地方

1. **以为「一个角色、干净画面」就够了。** 实际上 Calmlings 是特写，我们的海龟是带桌子的中景，脸只占画面三分之一。
2. **以为可以不开口。** Calmlings 每一条都是从第 0 秒开始唱的，没有一条是纯音乐配动作。不开口的是 Pudgy 和 Baboo，它们靠的是两个角色之间的关系。
3. **把 Pudgy 那条读成了「动作加反转」。** 只看文字记录看不出红叉和绿勾。
4. **分享率的「强」线定在 1%。** 这几条在 TikTok 上是 3%–4%，线已上调。
