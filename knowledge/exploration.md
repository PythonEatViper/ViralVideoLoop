# 探索地图：每条视频占一个格子，直到找到我们的爆款套路

2026-10-14 建立（老板：尽量探索不同设计理念，方向足够广，直到找到适合我们的爆款 pattern）。

## 两个固定栏目

| 栏目 | 时间（北京） | 做法 | 目的 |
| --- | --- | --- | --- |
| **翻拍** | 晚上 20:00–22:00（美东早上） | 借近 6 个月、多个频道、百万到千万播放的爆款，剧情和镜头基本照搬，换成我们的角色 | 检验「剧本」是不是我们没流量的主因 |
| **原创组合** | 早上 07:00–09:00（美东晚上黄金时段） | 从别的领域借结构，配原创钩子，追求少见 | 找只属于我们的东西 |

两个栏目同一天发，对比的是同一个账号、同一天的流量，差别主要来自内容本身。

## 维度（每条视频在每一维上选一个值，记进 post 的 variables）

| 维度 | 可选值 |
| --- | --- |
| 结构 | 翻拍 / 跨领域组合 / 歌 / 假教程 / 对比（错 vs 对）/ 反转在最后一秒 / 解说（体育、纪录片、新闻）/ POV |
| 角色 | 单只 / 一对 / 加道具角色（手机） |
| 声音 | 原创歌（Suno）/ 纯音乐加音效 / 画外解说 / 借平台流行声音 / 角色对白 |
| 钩子类型 | 一行标签（"sleeper build"）/ 第一人称的话 / 问题 / 数字 / 熟悉的格式（直播、新闻、纪录片）|
| 情绪 | 治愈 / 好笑 / 甜 / 紧张后放松 |
| 长度 | 7 秒以下 / 7–12 秒 / 12–18 秒 |
| 结尾 | 循环 / 反转 / 温暖收尾 / 提问 |

## 规则

1. **每条至少换一个维度上的值**，同一个组合不连拍两次。
2. **一个方向至少发 3 条再下结论**，单条数据不算数。
3. **晋级**：一个格子连续 3 条的 3 秒留存和分享率都高于账号平均，记成一条「有证据」的规律，之后加大比重。
4. **淘汰**：连续 3 条都在账号平均以下，这个格子暂停两周。
5. 每次复盘（skill `vvl-retro`）更新下面这张表。
