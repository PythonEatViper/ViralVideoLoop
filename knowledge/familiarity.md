# 借用观众脑子里已有的东西

2026-10-12 建立。起因是老板的一个想法：人脑里有很多现成的知识和感受（比如熟悉的旋律），合适的视频能把它们激活，再借着这股劲慢慢引导，可能对留存有用。

## 研究里对得上的部分

- **熟悉的音乐更能激活情绪和奖赏回路**。脑成像研究（Pereira 等，2011，PLoS ONE）发现，听熟悉的音乐时，边缘系统和奖赏相关区域比听陌生音乐时明显更活跃，熟悉度是关键因素。
- **期待本身就有奖赏**。Salimpoor 等（2011，Nature Neuroscience）发现，在音乐高潮到来之前的「期待」阶段就有多巴胺释放；预测和体验走的是两条不同的回路。
- **处理起来越省力，越容易喜欢**（处理流畅性、单纯曝光效应）。
- **没完成的东西会留在脑子里**（蔡格尼克效应）。有研究者用它解释「洗脑歌」：只放一段，反而更容易在脑子里循环。这个效应的重复实验结果不一致，只当假设用。
- **好笑 = 违反了预期，但又是安全的**（良性违反理论，McGraw 和 Warren）。改词的歌正是这样：旋律让人预测下一句，改掉的词打破预测，又无伤大雅。

这些研究的对象是听音乐、看广告、听笑话，没有一项是在短视频留存上做的。它们解释了为什么这个想法可能成立，证明要靠我们自己的数据。

## 变成做法

1. **第一秒给出一个认得出的东西**：一段公版旋律的头两个音、一个人人见过的手机界面。观众认出来的瞬间就有了预期，不需要解释设定。
2. **顺着预期走一步，再偏一步**：前半句按原样，后半句改词。一条视频里只偏一处。
3. **让旋律或句子到最后一秒才完整**：观众为了听完会留下。结尾停在快要收束的地方，重播时正好接上，可以循环。
4. **一条视频只借一样**。同时用熟悉的旋律、熟悉的界面和熟悉的台词，就又过载了。

## 我们的题材里现成可借的

| 类型 | 例子 | 注意 |
| --- | --- | --- |
| 公版旋律 | 《小星星》、勃拉姆斯摇篮曲、《划船歌》、《生日快乐》 | 流行歌的旋律有版权风险，不用 |
| 手机上人人见过的时刻 | 电量 1%、「存储空间已满」、每周屏幕时间报告、闹钟的「稍后提醒」、「你还在看吗？」 | 只做相似的样式，不复制真实界面和商标 |
| 固定句式 | 「Once upon a time…」、数羊、「five more minutes」 | — |
| 声音 | 通知的「叮」、闹铃 | 用素材库里的通用音效，不用系统原声 |
