# 通用爆款模式

这里只放**跨项目成立**的规律：在某个项目里升为「规则」、并且和具体题材无关的，由总监在周复盘时抄到这里，写明证据。项目自己的规律在 `projects/<项目>/db/learning.jsonl`，在看板「规律」页看。

目前还没有经过我们自己数据验证的条目。下面是从调研里来的起点，全部是假设：

| 模式 | 说法 | 我们的证据 |
| --- | --- | --- |
| 先放最强的一句 | 倒叙开场比顺叙开场的 3 秒留存高 | 0 条 |
| 点名式具体 | 精确的时间和数字比模糊的说法更让人觉得「说的是我」 | 0 条 |
| 怪设计，不怪人 | 自嘲和共情比说教更容易被分享 | 0 条 |
| 结尾留问题 | 投票或提问提高评论率 | 0 条 |
| 收藏和分享 | 比播放量更能预测后续增长 | EndScroll IG 2 条（2026-10-18 周复盘）：goose_keep_going 6h 只有 274 播放，但分享 1.5%、收藏 0.7%，42h 到 5.9 万；turtles_shell 6h 有 1,427 播放，分享 0.14%，停在 1.5K。还是假设 |
