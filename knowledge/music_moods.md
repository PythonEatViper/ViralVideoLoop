# 配乐：音乐跟着剧情走

更新：2026-10-11。

**原则**：剪辑跟着音乐走，音乐跟着情绪走。不要在整条视频底下铺一首歌（2026-10-11 试过，老板反馈太吵）。

## 情绪 → 音乐

| 剧情时刻 | 音乐怎么做 | 音量（相对人声） |
| --- | --- | --- |
| 钩子（0-3 秒） | 一个有辨识度的开场：悬疑低音、真人秀片头、或直接静音加一声重击 | 中 |
| 人物登场 | 每个角色一个短的主题乐句（2-3 秒），切镜头落在鼓点上 | 低 |
| 铺垫 / 对话 | 很轻的节奏垫底，人声一出就压低 | 很低 |
| 笑点之前 | **音乐突然停住**（唱片刮擦声或直接静音），台词说完再接上 | 静音 |
| 反转 | 音乐的高潮正好落在反转那一帧 | 高，短 |
| 尴尬 / 冷场 | 静音，加一声蟋蟀叫或长号下滑 | — |
| 心软的时刻 | 换成慢的钢琴或弦乐，只留一两个音 | 低 |
| 结尾提问 | 悬念音，停在没解决的和弦上 | 中 |

## 怎么落到文件里

- 每集的 `storyboard.md` 里加一栏「音乐」，每个镜头写上面的哪一种。
- 音乐库在 `assets/music/`，每首在 `assets/music/index.json` 里标好 `mood`、`bpm`、授权和来源。只收可商用的。
- `episode.json` 现在只支持一条 `music` 轨道。分段配乐先用多个 `sfx` 条目实现（每段一个文件，用 `start`、`dur`、`gain` 控制）。
- 发布时的平台热门音乐由推销员另加，音量调到最低；`post.json` 的 `add_music` 写明要不要加、加哪种情绪的。
