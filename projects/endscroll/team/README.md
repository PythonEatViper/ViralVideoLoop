# Standing instructions — shared and editable

One file per staff member (`<staff id>.md`) plus `everyone.md`. Whatever is written here is added to that staff member's instructions at its next run. Anyone on the team may edit these files directly, or add a line with:

    vvl instruct <staff id or everyone> "<instruction>" --by <who>

The dashboard's 团队 page shows each staff member's full current instructions and lets the boss add a line from the browser. The role descriptions these build on are in `engine/roles/` and are just as editable.
