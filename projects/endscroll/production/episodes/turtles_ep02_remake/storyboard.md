# 海龟 Ep 2（翻拍栏目，晚上 20:00–22:00 发）— sleeper build

- **原片**：@nataliireynoldss「sleeper build」，1935 万播放、4.8 万分享、7 秒。https://www.tiktok.com/@nataliireynoldss/video/7670020965245406477
- **原片结构**：一行字 `sleeper build` 从第一帧挂到最后。她站在床边，像健身房「秀身材」那样认真地转身、侧身、亮手臂；最后一秒抓起被子盖住自己倒头就睡。笑点是把健身黑话 sleeper build（看着普通其实很强）按字面理解成「睡觉型身材」。
- **我们只换角色**：Endy（绿色那只）照原片的动作和机位演一遍。镜头、节奏、那一行字都不改，这样才能检验「剧本是不是我们没流量的主因」。
- **时长**：7 秒，一个镜头，一个角色，720p，约 7 积分
- **在测什么**：同样的剧本换成我们的角色，流量能不能明显高过我们自己写的剧本
